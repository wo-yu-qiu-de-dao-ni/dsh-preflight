# preflight 安装说明（前置技能 v1.3.0）

## 这是什么

一个 Hermes 通用交付质量 skill：**生成前拆义务定验收标准（收单）→ 生成时按四层十二格纪律（输出）→ 交付前换评审身份自检（自检）**。

核心用途：让你派给 AI 的"帮我写一份方案/报告/文案"类任务，产出从"看起来完成了"变成"真的可以直接用"。

## 安装（2 分钟）

1. 找到你 Hermes 的 skills 目录：
   - 默认在 `D:\Hermes\skills\`（如果你设过 HERMES_HOME，就在 `<HERMES_HOME>\skills\`）
   - 如果你用的是某个 profile，则是 `D:\Hermes\profiles\<profile名>\skills\`
2. 把本目录整个 `delivery-preflight` 文件夹拷进 skills 目录（skill 名称为 preflight）
3. **重要**：Hermes 要求技能文件必须叫 `SKILL.md`——把拷进去的 `前置技能_v1.3.0.md` **重命名为 `SKILL.md`**（版本号在文件内的 frontmatter `version: 1.3.0` 字段里，不靠文件名）
4. 重启 Hermes（或开新会话）
5. 验证：发一句"帮我写一份周报，先拆一下验收标准"——AI 应该先给义务表和选项框，而不是直接开写

## 怎么用（示例）

**你**：帮我写一份新品上线的渠道落地方案

**AI（收单）**：
- 义务表：O1 首轮进哪几个渠道（明确清单非候选池）｜O2 各渠道准入条件与谁去核｜O3 分批时间安排｜O4 谁负责+首月资源口径
- 选项框：体裁=方案；详略=工作摘要；边界=只做渠道选择不做预算审批；……

**你勾选后，AI 才开始生成**，交付前还会附一份自检摘要（哪些格没过、还剩什么活要你补）。

## 反馈

验证中遇到问题（误判、太啰嗦、义务拆得不对），把"你输入的原话 + AI 的收单输出"反馈给吴仇。

## 附 A：DSH（DeepSeek Harness）环境安装

**推荐（桌面版，一步到位）**：左侧面板 → **插件** → 右上角**添加插件** → 粘贴仓库网址 `https://github.com/wo-yu-qiu-de-dao-ni/dsh-preflight` → 点击安装。装完重启，所有会话自动生效（规则注入 system prompt）。

**备选 1（CLI）**：下载 Release 页的 `dsh-preflight-1.3.0.tgz` → `dsh plugin --profile web add ./dsh-preflight-1.3.0.tgz` → 重启 → `dsh --profile web --dump-config` 验证出现 `# == dsh-preflight` 层。

**备选 2（纯文件方案，AGENTS.md）**：

1. 打开 DSH 的工作区目录（默认 `文档\deepseek-harness\default-workspace\`）
2. 新建/编辑 `AGENTS.md`，把下面这段极简版粘进去（AGENTS.md 是常驻指令、每个会话都注入，所以**用极简版，别粘全文**）：

```markdown
# 交付约定（前置技能 v1.3.0 极简版）

产出文档类任务（方案/报告/纪要/文案/邮件/需求表）按三段执行：
① 收单：保留任务原话作验收基准；从原话拆 3–6 条义务，每条带"做到什么程度算过关"的可判标准；用 ≤5 个选择题确认体裁/详略/格式/本轮边界（做什么不做什么）；跳过的记"未指定"并在开头"假设清单"集中标注（≤5 条），不许擅自替用户定边界。
② 输出：意图（回应什么任务/支撑什么决定/边界）→ 策略（明确选了什么+依据+何时改选，禁止只罗列选项）→ 执行（谁做什么何时完成+完成判据）→ 表达（结论与假设分开；未核实写"未核实"；禁套话重复模板句）。省略内容前过四问：当前阶段必须吗/属我该做的判断吗/全文确实没做吗/影响当前决定吗——不过的显式标注"建议·不属于本轮"，不许默默删。
③ 交付前：以评审视角重读全文按 0–10 逐层评分（10=本阶段必要工作已完成，5=关键判断做了一半，2=只给了材料与方向，0=需重新开展）；关键判断的引文/数字逐字回原文核对，对不上的降级为"不可采信"；附"交付体检摘要"（层分+结论+缺口+待确认项）。
依据只能来自用户提供的材料，没有就写没有，不许编；判不了写"未判定"，不许写成"没问题"。
```

3. 保存即可生效（新会话自动带上）。团队共用同一工作区 = 全员共用同一份约定。
4. 进阶（可选）：把 `@yiyunet/dsh-kill-ai-slop` 插件装进 DSH（插件窗口填包名），交付前的引文核对可从"自检"升级为引擎硬核对。

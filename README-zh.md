# 前置技能（dsh-preflight）使用说明

**一句话**：让 AI 产出文档前先立尺子（收单拆义务）、写的时候按尺子（四层输出纪律）、交付前自己量一遍（自检）——事后返工的成本远高于事前确认。

---

## 一、这是什么

一个交付质量规则包，提炼自开源反 AI-Slop 方法论（stop-slop / no-ai-slop / kill-ai-slop 系列，未复制代码），核心判断不是"文笔好不好、字段全不全"，而是：

> **这份交付还剩多少活要接收者补。**

三段规则：
1. **收单**：保留任务原话作验收基准 → 拆 3–6 条义务（每条带"做到什么程度算过关"的可判标准）→ 选项框确认体裁/详略/格式/本轮边界
2. **输出**：四层十二格纪律——意图（回应什么任务/边界）→ 策略（选了什么+依据+何时改选）→ 执行（谁做什么何时完成+完成判据）→ 表达（结论与假设分开、未核实写未核实、禁套话）
3. **自检**：交付前换评审视角重读全文，0–10 逐层评分（层分取本层最弱格），关键引文逐字核对，附体检摘要（缺口+待确认项）

底线：**判不了写"未判定"，不许把"我没看"印成"没问题"；依据只能来自提供的材料，没有就写没有，不许编。**

---

## 一·五、这个插件（dsh-preflight）具体做什么

装进 DSH 后，它只做一件事：**把上述三段规则注入 DSH agent 的 system prompt**（官方 `systemPrompt.section` 机制）。

| 项 | 说明 |
|---|---|
| 生效范围 | 全局——所有会话、每次请求都带规则（与 AGENTS.md 的工作区级不同） |
| 生效方式 | agent 收到产出文档类任务时自动按三段执行：先拆义务+选项框确认，再按四层纪律写，交付前自检附体检摘要 |
| 触发边界 | 纯问答/翻译/闲聊/检索不触发；轻重分流（短通知等轻任务跳过收单，关键邮件等重任务走全流程） |
| 档位 | `level: full`（完整规则，默认）/ `mini`（极简省 token，cordis.patch.yml 里改） |
| 硬约束 | 不依赖 agent"自觉"的底线：依据只能来自用户提供的材料，没有就写没有；判不了写"未判定"不许写成"没问题"；不输出 AI 生成概率 |
| 副作用 | 每次请求的 system prompt 增加约 1–2K token（full 档）——重任务省下的返工成本远高于此；介意就切 mini 或改用 AGENTS.md |
| 与 AGENTS.md 的关系 | 两者机制相同（都是指令注入），范围不同（全局 vs 工作区）——**二选一**，都装会重复注入浪费 token |

## 二、按你的环境选择装法

| 环境 | 装法 | 效果 |
|---|---|---|
| **DSH CLI** | 下载 `dsh-preflight-1.3.0.tgz` → `dsh plugin --profile web add ./dsh-preflight-1.3.0.tgz` → 重启 → `dsh --profile web --dump-config` 验证出现 `# == dsh-preflight` 层 | 全局生效（所有会话） |
| **DSH 桌面版** | 左侧面板 → **插件** → 右上角**添加插件** → 粘贴本仓库网址 `https://github.com/wo-yu-qiu-de-dao-ni/dsh-preflight` → 点击安装（本仓库 `lib/` 已提交且无构建脚本，不会被构建审批拦截） | 全局生效 |
| **DSH 桌面版（备选）** | 把"极简版规则"贴进工作区 `AGENTS.md`（默认 `文档\deepseek-harness\default-workspace\`） | 工作区生效，改规则就是改文件 |
| **Hermes** | 把 `hermes-skill/前置技能_v1.3.0.md` 拷入 skills 目录，**重命名为 `SKILL.md`** | 按需加载，触发词匹配 |
| **ChatGPT/Claude 等** | 把 `hermes-skill/安装说明.md` 附 B 的通用提示词版存为自定义指令 | 全局生效 |

## 三、怎么用（一次完整示例）

**你**：帮我写一份新品上线的渠道落地方案

**AI 收单**：拆义务表 + 选项框（体裁=方案 / 详略=工作摘要 / 本轮边界=只做渠道选择，不做预算审批……）

**你勾选后 AI 才开写**，交付时附体检摘要：

```
意图 92｜策略 83｜执行 75｜表达 83
结论：补充相关部分
缺口：E2 渠道准入核实时限未写明 → 补"谁+什么时候"去核
待确认项：首月预算口径待财务确认
```

## 四、规则全文与版本

- 规则以 `hermes-skill/前置技能_v1.3.0.md` 为准（DSH 插件内置文本是它的命令式转写）
- 版本号：v1.3.0（含两轮共 40 次攻防测试改进，29 处加固）

## 五、更新规则的方法

改规则 → 同步升版本（package.json + frontmatter）→ `npm pack` 出新 tgz → `gh release create v新版本 ./新tgz`。
